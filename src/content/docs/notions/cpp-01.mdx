**Objectif :** distinguer la valeur initiale d’une variable et une modification ultérieure, en observant les deux valeurs. **Prérequis :** [TOOL-01](../tool-01/) et [lire un premier programme](../programme-minimal/). **État :** un programme complet en C++17 et des fiches complémentaires sont disponibles à la lecture ; leurs projets autonomes à cloner ne sont pas encore publiés.

## Donner une première valeur

Nous voulons représenter le nombre de mesures déjà reçues. Le premier total connu est **0**. Pour illustrer une mise à jour, nous fournissons ensuite un autre total connu : **1**. Le programme ne reçoit aucune mesure et ne lit aucun capteur.

L’**initialisation** établit la valeur de départ. L’**affectation** remplace ensuite la valeur d’une variable qui existe déjà. Ces deux opérations correspondent à des moments différents.

## Prévoir puis observer les deux valeurs

La variable `measurement_count` représente un nombre de mesures, pas leur température. Nous attendons **0** à sa création, puis **1** après l’affectation. Le programme doit écrire chaque valeur sur sa propre ligne, sans message sur la sortie d’erreur, puis terminer avec le statut de réussite `0`.

Le modèle se lit de haut en bas. Chaque action « écrire la valeur puis un saut de ligne » regroupe deux instructions : écrire la valeur courante, puis terminer la ligne. Les écritures ne modifient pas le compteur.

Voici un programme complet pour ordinateur. Sa structure est celle de la première leçon ; la nouveauté est la variable dont nous lisons la valeur.

{/* example:program-measurement-observed */}
```cpp wrap
#include <iostream>

int main() {
    int measurement_count = 0;
    std::cout << measurement_count;
    std::cout << "\n";
    measurement_count = 1;
    std::cout << measurement_count;
    std::cout << "\n";
    return 0;
}
```

## Lire le nom pour retrouver la valeur

`int` précise ici que la variable contient un entier. `measurement_count` est le nom choisi pour désigner cette donnée. Dans la première instruction, nous déclarons cette variable et l’initialisons à zéro. Dans `measurement_count = 1;`, nous utilisons le nom existant pour remplacer sa valeur par un.

Dans `std::cout << measurement_count;`, le nom n’est pas entre guillemets : le programme lit la valeur courante de la variable et l’écrit sous forme de chiffres. Au premier affichage, elle vaut `0` ; au second, elle vaut `1`.

Compare ces deux expressions au moment où le compteur vaut encore zéro :

Aucune de ces deux instructions ne demande seule un saut de ligne. Dans notre programme, l’instruction suivante, `std::cout << "\n";`, termine chaque ligne. Le retour à la ligne du fichier source ne suffit pas. Tu peux retrouver cette distinction dans [suivre plusieurs affichages](../premiers-affichages/).

## Distinguer les mots

<thead>
<tr><th>Terme</th><th>Rôle dans ce programme</th></tr>
</thead>
<tbody>
<tr><td>Déclaration</td><td>Introduire le nom <code>measurement_count</code> et préciser son type <code>int</code>.</td></tr>
<tr><td>Initialisation</td><td>Établir sa valeur de départ, <code>0</code>, lors de sa création.</td></tr>

</tbody>
</table>

Une même instruction peut déclarer une variable, la créer et l’initialiser. Le signe `=` participe ici à l’initialisation dans la première instruction et à l’affectation dans la suivante ; il ne pose pas une question d’égalité. La distinction générale entre déclaration et définition sera approfondie avec l’organisation du programme en plusieurs fichiers.

## Choisir explicitement la valeur de départ

Un entier local ordinaire, créé à l’intérieur d’une fonction sans valeur initiale explicite, ne reçoit pas automatiquement zéro. Pour notre compteur, nous choisissons donc explicitement zéro comme valeur de départ. Nous n’allons pas lire une variable non initialisée pour essayer de deviner sa valeur.

Zéro convient au nombre de mesures déjà reçues au démarrage ; il ne remplace pas automatiquement une mesure absente. Une autre donnée peut nécessiter une autre valeur initiale.

## Lien avec l’embarqué

Initialiser le compteur ne lance pas le capteur. Lui affecter `1` enregistre le total fourni dans notre exemple : cela ne détecte pas une arrivée, ne vérifie pas une entrée et ne calcule pas le total précédent plus un. Ces sujets viendront dans d’autres leçons.

**À retenir :** initialiser établit la première valeur ; affecter remplace ensuite celle d’une variable existante. Afficher cette variable permet d’observer sa valeur au moment de l’écriture.
